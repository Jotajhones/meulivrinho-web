# Meu Livrinho

## Sobre o Projeto
O Meu Livrinho é uma plataforma de leitura digital infantil focada em controle parental passivo e segurança nativa. O sistema atua como um "Walled Garden", um ecossistema 100% fechado, sem acesso à internet externa, sem anúncios e sem interações de terceiros. O projeto atual consiste em um e-reader nativo desenvolvido em React, focado em otimizar e transformar arquivos (como ePub e PDF) em interfaces lúdicas.

> **Status do Projeto:** Este MVP está em fase de teste com o público para lançamento da plataforma no modelo freemium.

## Tecnologias Utilizadas
* **Front-end:** React com CSS Puro (Vanilla CSS), mantendo a interface fluida, customizada e livre de dependências de frameworks externos.
* **Back-end & Banco de Dados:** Supabase.
* **Infraestrutura e Deploy:** Vercel.

## Funcionalidades do MVP
* **Gestão Centralizada:** Controle parental onde o responsável cria o cadastro e vincula o perfil da criança.
* **Importação de Biblioteca:** Permite que o usuário traga e-books que já possui para dentro do ecossistema blindado.
* **Leitura Amigável e Descomplicada:** Interface pensada para o público infantil.

## Próximos Passos
* Conversão da base de dados atual totalmente para e-book.
* Implementação de ferramentas que deixam a leitura mais atrativa para o público infantil.
* Desenvolvimento de aplicação nativa.
